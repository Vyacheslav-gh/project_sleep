# Влияние приложения для медитации на время засыпания

## Цель проекта
Проверить гипотезу о том, что использование вечерних медитаций в мобильном приложении сокращает время засыпания пользователей.

## Описание данных
Датасет содержит анонимизированные данные о времени засыпания пользователей (в минутах) до и после начала использования приложения.

## Установка и запуск под Windows
1. Откройте терминал или командную строку и перейдите в папку вашего проекта:

```bash
cd путь/к/проекту
```
2. Создает локальную папку с изолированным интерпретатором и библиотеками:
```bash
python -m venv venv
```
3. Перед установкой библиотек окружение необходимо активировать:
```powershell
venv\Scripts\Activate.ps1
```
4. Установите Jupyter Notebook и зависимости проекта :
```bash
pip install notebook
pip install -r requirements.txt
```
5. Запустите сервер:
```bash
jupyter notebook
```
6. В браузере откроется интерфейс со списком файлов папки. Нажмите на нужный .ipynb файл, чтобы открыть проект
7. Запускайте ячейки с кодом по очереди через Shift + Enter или весь проект  Restart & Run All


## Главный вывод
Приложение для медитации статистически значимо сокращает время засыпания. Время засыпания в среднем сократилось примерно на 3 минуты (от 2 до 4 минут с учётом неопределённости оценки), то есть примерно на 9% от исходного уровня — заметный практический эффект.
